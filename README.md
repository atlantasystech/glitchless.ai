# Glitchless Technologies — Intelligent Digital Operations & AI Automation

Production-ready marketing and digital operations web platform for **Glitchless**, an Indian IT-services and AI-automation brand helping high-growth D2C brands, B2B manufacturers, and agencies automate ecommerce, customize open-source CRMs, deploy agentic AI, and build bespoke digital applications.

---

## 🎨 Design Direction & Inspiration

- **Clay.com Inspiration**: Product-led structural layout, spacious sections, high-density bento cards, realistic live operational widgets, and conversion hierarchy.
- **Glitchless Brand Identity**: Light-first aesthetic with deep ink/navy contrast sections (`#090e1a`), clean off-white backgrounds (`#fbfcfd`), subtle violet-to-cyan gradient accents, glassmorphic panels, rounded 16–24px components, crisp typography, and restrained motion.
- **Data Sovereignty & Open Source**: Specializing in self-hosted open-source enterprise stacks (n8n, Odoo, ERPNext, PostgreSQL, Supabase) eliminating per-seat SaaS tax.

---

## 🚀 Tech Stack

- **Framework**: Next.js App Router
- **UI Library**: React & TypeScript
- **Styling**: Tailwind CSS with custom glassmorphism and bento utilities
- **Icons**: Lucide React
- **Animations**: Framer Motion & CSS keyframe micro-animations
- **SEO & GEO**: Dynamic `sitemap.ts`, `robots.ts`, Open Graph images, and full JSON-LD structured data (Organization, LocalBusiness, Service, HowTo, FAQPage, Article, BreadcrumbList)
- **Deployment**: Zero-configuration Vercel deployment & Sovereign Cloud VPCs

## 🛠️ Local Development Setup

### 1. Prerequisites
- Node.js `v20.x` or higher
- npm `10.x` or higher

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to explore the website.

### 4. Build for Production
```bash
npm run build
npm run start
```

## 🌐 Deployment to Vercel

Glitchless is optimized for one-click deployment on Vercel:

1. Push your repository to GitHub / GitLab / Bitbucket.
2. Import the project into the [Vercel Dashboard](https://vercel.com/new).
3. Framework Preset: **Next.js**
4. Build Command: `next build`
5. Output Directory: `.next`
6. Click **Deploy**.
